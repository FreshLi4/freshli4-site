# Description

维护 `/pitch-deck` 导览与项目详情，使名称、定义、阶段和范围对应最新用户确认。保留原有十二项，新增《先干为敬》《义体医生模拟器》，并拆出独立抓宠提案 For Bond，共十五项。其余原本不在 pitch deck 的项目不新增页面。

## 当前内容与范围

- 《人模人样》采用关卡集、多组动态合作竞争；超市拿东西是已有首关，办公室打卡只是可能例子。正式联机为 P2P 房主/访客与自动迁移，按用户措辞写为初步验证实现，不宣称完整多人实玩验收。
- 《古堡惊魂》共同胜负，以 PEEK 量级的轻量动作为主，解谜考验配合；已有大厅试走，完整夺宝逃生未实现。回程计划让房间逐个坍塌，怎样快速重过关卡尚未想好；去程状态影响回程方便程度仍为候选。
- 《铁甲钢拳》以改装策略主导，模块完全自由拼装；更高级别带来更多奖金/模块，特殊头目解锁特殊模块。赛前编写攻击策略的编程模拟器方案仍是候选，没有可玩工程。
- 《货柜大乱斗》竞拍取得整柜物品；贴标后计费、停用、防偷，未贴标可以使用。活捉后贴标比打死做标本更值钱。偷抢与干扰等玩家互动仍未想好，旧 H5 不算新 3D 原型。
- 《奇货远航》明确纯单人。亲自操船加随机发现、或航线选择加文字事件均为候选；工作量、途中空档、整体风格/乐趣，以及损失、保留和航程目标怎样支撑循环仍待展开。
- 《二重证言》当前只推进美国篇，保留 1922／1932 固定十年差、九案、实时笔记本与分头取证。玩法方向已清晰，主要设计案情和每案结案方式。其他城市篇章为 TBD；既有主题/反派提案不提升为定案。
- 《迷雾城堡》单独保留维护城堡方向，暂时待定。用户说明部分原有核心构想已融入 LEBAB。抓宠拆为 For Bond，同步回合战斗是较明确的核心，可能先验证该部分，战斗外玩法尚未想好。
- 《跃入迷城》保留角色/战斗/AI/奖励沙盒事实，整体游戏与 Demo 方案仍未想好，不把旧任务拆分当成设计定案。《SLAM DRUNK》改为暂时待定，保留原概念，不继续写作筹备中。
- 两款免费游戏作为小游戏想法探索，以传统外循环承载新的内循环，不扩展付费或长期运营承诺。观澜先完成现有作品，同系列其他案件衍生分支待定。
- 《先干为敬》保留三轮供酒、玩家首拳才升级乱斗、停酒与清场，酒保单方处罚不算开打；补充落后者攻击更饱者、获得其呕吐物加分以鼓励混战。P2P 和常规匹配大厅明确，不把人数或连续多局结构列为产品缺口。Bottoms Up! 仍为英文候选。
- 《义体医生模拟器》明确清债可以构成一个结束，其余循环先参考《深空当铺》展开；不自动照搬参考作品的全部系统，不补造正式英文名、原型或美术，不另建游戏仓库。
- For Bond、维护城堡方向及其他暂无对应图稿的项目使用标题卡片，不生成临时素材。保持三个分区、既有 URL、首页入口与 noindex 行为。
- 本轮只修订官网本地草稿与检查，不提交、推送或部署，不归档、删除或改动游戏仓库。子不语、后室、Planteer 等不新增条目；不触碰已发售产品及桌游项目。
