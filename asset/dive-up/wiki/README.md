# 《调查深入》Wiki 资料组织

这里是网站规则与卡牌资料的内容源。以后优先修改 Markdown；CSV 只保存适合筛选、统计和排序的结构化字段。

## 目录约定

```text
wiki/
├── rule/
│   ├── 规则指引书.md
│   ├── 调查附录.md
│   └── 判例.md
├── card/
│   ├── 调查员/职业_名字/
│   │   ├── 卡面.md
│   │   ├── 角色故事.md
│   │   └── 创作背景.md
│   ├── 策略卡牌/卡名/
│   │   ├── 卡面.md
│   │   └── 创作故事.md
│   ├── 环境卡牌/卡名/
│   ├── 情报卡牌/卡名/
│   └── 辅助卡牌/卡名/
├── index.csv
└── <类别>.csv
```

每张卡牌的文件夹名是稳定的人类可读路径；调查员姓名中的中点 `·` 统一替换为连字符 `-`。`index.csv` 是总索引，类别 CSV 继续保留原始字段，并追加 `Wiki相对目录`。

## 内容来源优先级

1. 页面正文、卡面效果、故事和规则解释：对应 Markdown。
2. 卡牌名称、职业、费用、数量、版本等筛选字段：类别 CSV。
3. 传统搜索和 AI：由构建脚本读取上述 Markdown，自动生成统一资料索引。
4. `src/generated/` 与 `public/_wiki-search/` 是构建产物，不要手工修改。

新增或修改资料后运行 `npm run generate:wiki`；部署构建会自动运行同一流程。
