# 翻译文件约定

每次部署都会重新读取本目录下的 `zh.po`、`en.po` 和 `ja.po`。

- `msgctxt "term"`：规则术语。网站按最长词优先替换，因此新增或修订术语不会被短词截断。
- `msgctxt "text"`：完整句子或段落。只有存在完整译文时才替换；没有译文时保留原文，同时仍可替换其中已登记的术语。
- `msgctxt "fragment"`：Markdown 行或规则页文本片段。用于把连续多行合并后的正文也完整替换；网站仍只在文本节点中替换，不会改动 HTML 的 id、链接或属性。

Markdown 是中文规范原文。英文和日文 PO 当前是机器初译，后续可以直接在对应 `msgstr` 上手动精调；不要把术语翻译写进 Markdown，这样改术语时不需要逐篇改内容。
